# Builds

Create one directory per independent build.

Use this naming convention:

```text
YYYY-MM-DD-short-descriptive-name
```

Examples:

```text
2026-10-14-campaign-dashboard
2026-10-14-card-offer-prototype
2026-10-15-research-portal
```

Start from the checklist in `_template/README.md`. Keep unrelated builds isolated from one another.
