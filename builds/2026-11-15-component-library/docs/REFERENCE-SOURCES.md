## How to save a new style

Record style ID, 2-3 screenshot references, reference URL and license status, narrative purpose, palette, typography, spacing, motion, image treatment, sample cover, chapter, visual, data and closing slide. A style is a reference and token recipe, not a copied proprietary deck.
