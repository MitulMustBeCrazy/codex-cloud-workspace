# Deck Template Library

## Distinct concepts

**Visual style**: design vocabulary including palette, fonts, grid, motion and media treatment.

**Narrative blueprint**: sequence of persuasive/storytelling beats for an audience.

**Slide pattern**: one composition, such as chapter opener, reveal, media grid, chart, quote or comparison.

**Reference source**: example or inspiration, with URL, creator, license and provenance.

## V1 visual styles

1. Editorial Minimal: high-whitespace strategy deck.
2. Cinematic Dark: sonic/brand story with film and atmospheric media.
3. Institutional Premium: leadership-ready, confident visual identity.
4. Bold Monotype: decisive campaign pitches with punchy reveals.
5. Data First: marketing performance and KPI evidence.
6. Human Narrative: photographic, culturally grounded storytelling.

## Future template acceptance criteria

Each fully implemented template should include:
- A rendered cover, section opener, content narrative, data/chart, media showcase and conclusion.
- Dark/light or at least one documented color mode.
- Editable fonts/colors without changing content.
- Single-click slide previews and optional motion preview.
- 16:9 desktop presentation and readable mobile review.
- Clear original/third-party credits, license status and source.
- User prompt identifier, for example: "Use Cinematic Dark with the Brand Campaign blueprint and the media gallery."

No external theme or proprietary commercial template is bundled in v0.1.
